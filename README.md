# MIHIN'S ARCADE — Portfolio

The personal portfolio of **Mihin Merchant**, Unity developer — presented as a retro arcade cabinet: an 8-bit boot gate, a WebGL shader hero with a starfield, a 3D game-cartridge project shelf, flip-to-reveal skill chips, and a patch-notes footer.

**Live:** https://meehn69.github.io

## Stack

Plain HTML, CSS and vanilla JavaScript — no framework, no build step. Motion is GSAP + ScrollTrigger; the hero runs a small custom WebGL shader. All text content lives in `js/content.js` as data and renders into static section shells, so every list on the site can grow or shrink freely.
